# Мой ИИ-агент (My-AI-agent)

Практические работы по учебной практике УП.01.
Тема итогового проекта: **поиск ошибок в коде**.
Автор: Лучаев Ефим Романович, группа 1ИИ-1-11.

Репозиторий содержит все выполненные работы по дням: от основ Python и анализа
данных (дни 1–10) до разработки ИИ-агента и RAG-поиска (дни 13–19).
Каждый день лежит в отдельной папке с понятным названием.

## Итоговый агент

Итоговая программа — [`Итоговый агент/agent.py`](Итоговый%20агент/agent.py).
Подробное описание: [`Итоговый агент/README.md`](Итоговый%20агент/README.md).

Агент отвечает на вопросы об ошибках в Python. Он не отправляет вопрос в модель
сразу: сначала ищет подходящие фрагменты в базе знаний (RAG), затем передаёт
найденный контекст в GigaChat и показывает ответ вместе со списком источников.

Что умеет:

- вести диалог с историей (последние 3 обмена);
- команды `выход`, `очистить`, `история`;
- не отправлять пустой запрос;
- честно сообщать, если в базе знаний нет подходящего фрагмента;
- печатать источник и `chunk_id` для каждого ответа;
- писать журнал событий в `agent.log` без ключа API.

### Как запустить

1. Установить Python 3.13+ и зависимости:

   ```
   pip install gigachat python-dotenv numpy
   ```

   Для нейросетевых эмбеддингов (необязательно):

   ```
   pip install sentence-transformers
   ```

2. В корне проекта создать файл `.env`:

   ```
   GIGACHAT_CREDENTIALS=ваш_ключ
   GIGACHAT_SCOPE=GIGACHAT_API_PERS
   ```

   `.env` в репозиторий не загружается.

3. Запустить из корня проекта:

   ```
   python "Итоговый агент/agent.py"
   ```

4. Задавать вопросы по-русски, например:
   `Почему возникает NameError и как её исправить?`
   Для выхода ввести `выход`.

### Как агент получает ответ

1. Загружает 13 чанков из `19 Эмбеддинги/chunks/` и считает их эмбеддинги.
2. Считает косинусное сходство вопроса с каждым чанком.
3. Берёт top-3 фрагмента. Если лучший score ниже порога `0.12`, ответ не
   генерируется: агент сообщает, что в базе нет подходящей информации.
4. Добавляет найденные фрагменты в промпт вместе с вопросом и историей диалога.
5. Отправляет запрос в GigaChat-2, печатает ответ и источники.

Если библиотека `sentence-transformers` не установлена, используется резервный
учебный эмбеддер на хешах слов и n-грамм (2048 чисел). Алгоритм поиска тот же;
с установленной библиотекой автоматически используется мультиязычная модель
`paraphrase-multilingual-MiniLM-L12-v2`.

### Проверка

Вывод реального запуска: [`Итоговый агент/console_final.txt`](Итоговый%20агент/console_final.txt).

- Обычный запрос «Почему возникает NameError и как её исправить?» → ответ по
  фрагменту `python_errors.txt`, `chunk_id=0`, score `0.2878`.
- Пустой ввод → «Запрос пустой. Введите вопрос по Python…», запрос не отправлен.
- Вопрос «Какая завтра погода?» → «В базе знаний нет подходящего фрагмента
  (лучший score 0.0698 < порога 0.12)».

## Запуск остальных работ

1. Python 3.13+ и пакеты: `pip install gigachat python-dotenv numpy pandas matplotlib`.
   Для Дня 19 опционально `sentence-transformers`.
2. В корне проекта — `.env` с `GIGACHAT_CREDENTIALS` и `GIGACHAT_SCOPE`.
3. Перейти в папку нужного дня и запустить нужный файл, например:
   `python main.py` или `python final_day15.py`.

## Важно

`.env`, `.venv/`, `__pycache__/` и методички (`*.docx`) в репозиторий не
выгружаются. Ключ GigaChat хранится только локально. Сертификат `certs/`
лежит в папках дней, которым нужен доступ к API.
