# Итоговый ИИ-агент: поиск ошибок в коде

Агент отвечает на вопросы об ошибках в Python. Сначала он ищет подходящие
фрагменты в базе знаний, затем передаёт их в GigaChat и показывает ответ
вместе с источниками.

## Состав

| Файл | Назначение |
|---|---|
| `agent.py` | основная программа: диалог, поиск, запрос к GigaChat, вывод источников |
| `console_final.txt` | реальный запуск: обычный вопрос, пустой ввод, вопрос вне базы |
| `agent.log` | журнал событий без ключа API (создаётся при запуске) |

Агент использует наработки предыдущих дней:

- `../19 Эмбеддинги/embeddings.py` — эмбеддинги, косинусное сходство, `search()`;
- `../19 Эмбеддинги/chunks/` и `chunks_summary.csv` — 13 чанков базы знаний;
- `../13 Промпт-шаблоны/prompts.py` — основа системной инструкции;
- `../15 Ошибки и Pydantic/certs/` — корневой сертификат для GigaChat.

## Запуск

Из корня проекта:

```
pip install gigachat python-dotenv numpy
python "Итоговый агент/agent.py"
```

В корне должен лежать `.env`:

```
GIGACHAT_CREDENTIALS=ваш_ключ
GIGACHAT_SCOPE=GIGACHAT_API_PERS
```

`.env` не загружается в GitHub.

## Как обрабатывается запрос

1. `load_embedder()` загружает модель эмбеддингов. Если
   `sentence-transformers` не установлена, включается резервный учебный
   эмбеддер на хешах слов и n-грамм.
2. `load_chunks()` читает 13 чанков из Дня 19 вместе с `source` и `chunk_id`.
3. `search()` считает косинусное сходство вопроса с каждым чанком и возвращает
   top-3.
4. Если лучший score меньше `0.12`, агент не вызывает модель, а пишет:
   «В базе знаний нет подходящего фрагмента».
5. Иначе найденные фрагменты добавляются в промпт вместе с вопросом и
   историей диалога.
6. `client.chat.create()` отправляет запрос в GigaChat-2.
7. Ответ печатается вместе со списком источников; событие записывается в
   `agent.log`.

## Команды

- `выход` — завершить работу;
- `очистить` — удалить историю диалога, оставив системную инструкцию;
- `история` — показать количество сообщений и их роли.

## Проверка

Файл [`console_final.txt`](console_final.txt) содержит три случая.

**Обычный запрос.** Введено: `Почему возникает NameError и как её исправить?`
Агент нашёл `python_errors.txt`, `chunk_id=0` (score `0.2878`) и объяснил
причину ошибки и способ исправления.

**Пустой ввод.** Введена пустая строка. Агент ответил: «Запрос пустой. Введите
вопрос по Python…». Запрос не ушёл ни в поиск, ни в GigaChat.

**Нет ответа в базе.** Введено: `Какая завтра погода?` Лучший score `0.0698`
ниже порога `0.12`, поэтому агент сообщил, что подходящего фрагмента нет.
Модель не вызывалась, случайный ответ не выдавался.
