Python — язык программирования общего назначения.
Переменная хранит значение и имеет имя.
Для вывода текста используется функция print().
Для ввода данных с клавиатуры используется input().
Условие if выполняет код только при истинном условии.
Цикл for повторяет действия для каждого элемента.
Комментарий начинается с символа #.
