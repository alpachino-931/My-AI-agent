Работа с файлами начинается с функции open().
Файл можно открыть для чтения или записи.
Режим r читает данные, режим w перезаписывает файл.
Конструкция with закрывает файл автоматически.
Кодировку лучше указывать явно: encoding="utf-8".
Метод read() читает весь текст, readlines() возвращает список строк.
