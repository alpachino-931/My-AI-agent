=== 1. История после одного обмена (без API) ===

Один полный обмен
Длина messages: 3
  1. system
  2. user
  3. assistant
Предсказание: 1 system + 1 пара = 3 элемента. Совпало.

=== 2. История после двух обменов (без API) ===

Два полных обмена
Длина messages: 5
  1. system
  2. user
  3. assistant
  4. user
  5. assistant
Предсказание: 1 + 2 * 2 = 5 элементов. Совпало.
Обменов 2, а элементов 5, потому что system не относится к обменам.

=== 3. Цикл ввода без API ===
Доступные команды: выход, история, очистить.
Любой обычный текст добавляет пару user + тестовый assistant.
Пустая строка пропускается и историю не меняет.

Вы: 
После нового обмена
Длина messages: 3
  1. system
  2. user
  3. assistant

Вы: Пустой ввод пропущен, история не изменилась.

Вы: 
Текущая история
Длина messages: 3
  1. system
  2. user
  3. assistant

Вы: История очищена: остался только system.

После очистки
Длина messages: 1
  1. system

Вы: 
После нового обмена
Длина messages: 3
  1. system
  2. user
  3. assistant

Вы: Демонстрация завершена.

=== 4. Ограничение истории (max_pairs = 3) ===

До сокращения (4 пары)
Длина messages: 9
  1. system
  2. user
  3. assistant
  4. user
  5. assistant
  6. user
  7. assistant
  8. user
  9. assistant

После сокращения (не больше 3 пар)
Длина messages: 7
  1. system
  2. user
  3. assistant
  4. user
  5. assistant
  6. user
  7. assistant

Проверка состава после сокращения:
  Длина равна 7: True
  Первый элемент system: True
  Первая пара удалена: True
  Сохранены пары 2, 3, 4: True
  Порядок user/assistant не нарушен: True

Итог: при max_pairs = 3 в истории остаётся не больше 7 сообщений.
