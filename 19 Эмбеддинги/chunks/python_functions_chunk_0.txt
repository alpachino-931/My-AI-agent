Функция объявляется словом def.
Имя функции описывает действие, которое она выполняет.
Параметры передаются в скобках после имени.
return возвращает результат вызывающему коду.
Функция без return возвращает None.
Локальные переменные видны только внутри функции.
Функцию удобно вызывать несколько раз
