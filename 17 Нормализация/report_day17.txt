3. КОД clean_line()
def clean_line(line: str) -> str:
    line = line.replace("\u00a0", " ")
    line = line.replace("\t", " ")
    return " ".join(line.split())

Что делает:
- неразрывный пробел заменяется обычным;
- табуляция заменяется пробелом;
- split() делит строку по любым пробельным символам;
- join() собирает слова через один пробел и убирает пробелы по краям.

4. КОД normalize_text()
def normalize_text(text: str, drop_service_lines: bool = False) -> str:
    clean_lines = []
    for line in text.splitlines():
        line = clean_line(line)
        if line == "":
            continue
        if drop_service_lines and line.lower() in SERVICE_LINES:
            continue
        if line not in clean_lines:
            clean_lines.append(line)
    return "\n".join(clean_lines)

Функция очищает каждую строку, пропускает пустые, удаляет точные дубли
и сохраняет порядок строк. Служебные строки удаляются только при явном
флаге drop_service_lines=True.

13. ОТВЕТЫ НА КОНТРОЛЬНЫЕ ВОПРОСЫ
1. Очистка текста — удаление явного мусора: лишних пробелов, табуляций,
   пустых строк, дублей и ненужных служебных пометок.
2. Нормализация — приведение текста к единообразному виду, чтобы одинаковые
   данные выглядели одинаково.
3. Для RAG это важно, потому что меньше мусора попадает в чанки, поиск идёт
   по чистому тексту, дубли не повторяются в результатах, проще сравнивать
   документы и меньше общий объём корпуса.
4. strip() удаляет пробельные символы в начале и в конце строки.
5. Табуляция — символ \t, горизонтальный отступ, часто появляется при
   копировании из таблиц.
6. replace() заменяет один фрагмент строки другим.
7. strip() работает только с краями строки и не трогает пробелы внутри.
8. Несколько пробелов между словами убирают через split() и join():
   " ".join(text.split()).
9. split() без аргументов делит строку по любому количеству пробельных
   символов и не создаёт пустых элементов.
10. join() собирает список строк в одну строку с указанным разделителем.
11. splitlines() разбивает текст на список строк по переводам строк.
12. Пустые строки не добавляют в результат: if line != "".
13. Точный дубль — строка, полностью совпадающая с уже добавленной.
14. Повтор может быть смысловым, поэтому нельзя удалять все повторы без
    понятного правила; сегодня удаляются только точные дубли строк.
15. lower() переводит буквы в нижний регистр.
16. Весь документ не переводят в lower(), потому что названия, аббревиатуры
    и код теряют читаемость; lower() применяется только для сравнения.
17. Неразрывный пробел (\u00a0) не даёт разрывать слова при переносе;
    после копирования из веб-страниц его заменяют обычным пробелом.
18. Сравнение объёма до и после показывает эффект очистки и помогает
    заметить потерю важного текста.
19. percent = (before - after) / before * 100.
20. Визуальная проверка нужна, чтобы убедиться: текст не стал пустым,
    важные строки и код сохранились, структура понятна.
21. normalize_text() очищает каждую строку, пропускает пустые строки,
    удаляет точные дубли и собирает результат через \n.
22. Следующий этап — разбиение нормализованных документов на чанки.
23. После чанкинга — эмбеддинги и векторный поиск.
