Список в Python хранит несколько значений по порядку.
Элементы списка записываются в квадратных скобках.
Нумерация элементов начинается с нуля.
Метод append() добавляет элемент в конец списка.
Срез list[1:3] возвращает часть списка.
Функция len() возвращает количество элементов.
Список можно изменить после создания.
