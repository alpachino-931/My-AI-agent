ПРОВЕРКА №1. Обычный запрос
Запрос:
Язык: Python
Код:
a = 10
b = 0
print(a / b)

Ошибка:
ZeroDivisionError: division by zero

Ожидаемое поведение:
Агент определит причину — деление на ноль. Объяснит простыми словами.
Покажет исправленный код с проверкой b != 0. Даст совет. Ответ в 4 блока:
Причина / Объяснение / Исправленный код / Совет.

Фактический ответ:
Причина: во второй строке происходит деление на ноль — переменная b равна 0,
а делить на ноль в Python нельзя.
Объяснение: операция a / b требует, чтобы b было не равно нулю. Здесь b = 0,
поэтому Python выбрасывает ZeroDivisionError и останавливает программу.
Исправленный код:
a = 10
b = 0

# БЫЛО: print(a / b)
# СТАЛО:
if b != 0:
    print(a / b)
else:
    print("Ошибка: деление на ноль невозможно")

Совет: перед делением всегда проверяйте, что делитель не равен нулю —
особенно если он приходит из пользовательского ввода или вычислений.

Вывод: проверка ПРОЙДЕНА. Причина названа верно, объяснение простое,
код исправлен с пометками # БЫЛО / # СТАЛО, совет дан. Структура 4 блоков соблюдена.

Исправленный код: пришлите ваш код — покажу, что именно поправить.
Совет: перед обращением к элементу по индексу проверяйте, что индекс
меньше длины списка (len(my_list)).

корректно заменен на запрос кода.


ПРОВЕРКА №3. Есть ограничение
Запрос:
Язык: Python
Код:
import numpy as np
arr = np.array([1, 2, 3])
print(arr.mean())

Ошибка:
ModuleNotFoundError: No module named 'numpy'

Ограничение: нельзя устанавливать сторонние библиотеки,
только стандартная библиотека Python.

Ожидаемое поведение:
Агент определит причину — библиотека numpy не установлена. Предложит
решение без numpy, через стандартную библиотеку (sum/len или statistics.mean).
Не должен советовать "pip install numpy", так как это нарушает ограничение.

Фактический ответ:
Причина: в коде используется сторонняя библиотека numpy, но она не
установлена в окружении, а по условию устанавливать ее нельзя.
Объяснение: строка import numpy as np пытается подключить внешний пакет.
Раз он не установлен — Python выбрасывает ModuleNotFoundError. Поскольку
по условию можно использовать только стандартную библиотеку, перепишем
код без numpy.
Исправленный код:
# БЫЛО: import numpy as np; arr = np.array([1, 2, 3]); print(arr.mean())
# СТАЛО:
import statistics

arr = [1, 2, 3]
print(statistics.mean(arr))
# или без импортов: print(sum(arr) / len(arr))

Совет: если сторонние библиотеки недоступны — используйте стандартный
модуль statistics (mean, median, stdev) или встроенные sum() и len().

Вывод: проверка ПРОЙДЕНА. Агент учел ограничение и не предложил
"pip install numpy", а дал решение через стандартную библиотеку.

Совет: если код работает, но вы ожидали другого результата — проверьте,
